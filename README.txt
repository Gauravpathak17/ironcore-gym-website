# IRONCORE FITNESS — Gym Website Demo

A responsive portfolio/demo website for NovaWeb Studio.

## Run
Open `index.html` in a browser. No build tools are required.

## Before showing a real client
Replace:
- Demo gym name/logo
- WhatsApp number `919999999999`
- Phone number and address
- Demo trainer names/photos
- Demo testimonials
- Demo transformation images
- Pricing
- Schedule
- Social links
- Image URLs if you want local assets

## Main features
- Responsive desktop/tablet/mobile layout
- Sticky navigation + mobile menu
- Hero section
- Animated statistics
- Programs
- Trainers
- Membership pricing
- Membership buttons pre-fill enquiry
- Transformation section
- Weekly class schedule tabs
- Gallery
- Testimonials
- Contact form → WhatsApp enquiry
- Floating WhatsApp button
- Scroll reveal animations
- Back-to-top button
- Loading screen
- SEO description/meta theme color

This is a fictional demo. Verify all claims, testimonials, prices and client results before publishing for a real business.
